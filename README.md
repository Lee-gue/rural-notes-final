# 安大乡村教育笔记

> 守望乡野，共育希望

一个关于安徽大学乡村教育公益项目的静态展示网站。

## 在线预览

本项目为纯静态网站，可直接在浏览器中打开 `index.html` 查看。

## 项目结构

```
.
├── index.html          # 主页面
├── styles.css          # 样式文件
├── script.js           # 交互脚本
├── background.jpg      # 首页背景图
├── activity-*.jpg      # 活动纪实图片
├── cover-*.jpg         # 活动封面图
├── photo-*.jpg         # 活动剪影照片
├── post-*.jpg          # 投稿卡片封面
├── douyin-*.png/jpg    # 抖音相关素材
├── sponsor-*.jpg       # 赞助相关素材
├── wechat-qrcode.png   # 微信二维码
└── README.md           # 项目说明
```

## 主要板块

- **首页**：项目介绍与愿景
- **项目进展**：展示最新动态
- **活动纪实**：记录往期活动
- **合作基地**：合作伙伴展示
- **团队成员**：团队介绍
- **青春笔记**：投稿与感悟分享
- **FAQ**：常见问题与留言

## 技术栈

- HTML5
- CSS3
- JavaScript (Vanilla)

## 使用说明

1. 克隆仓库到本地
2. 直接用浏览器打开 `index.html` 即可
